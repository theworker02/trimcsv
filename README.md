# trimcsv

Trim digests and csv fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/trimcsv/

## Install / run

```bash
git clone https://github.com/theworker02/trimcsv.git
cd trimcsv
node src/cli.js
node --test
```
